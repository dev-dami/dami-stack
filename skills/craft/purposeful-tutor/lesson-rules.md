# Lesson rules

Each lesson is a single numbered HTML file that stands alone and is set with real typographic care.

## Scope

- It covers one small thing the purpose calls for.
- It fits within working memory.
- It gives a concrete win just within reach.
- It carries just enough knowledge for the skill at hand, then goes straight to practice.

## Practice

- Give immediate feedback, automatic where possible.
- Prefer retrieval over rereading. Bring back earlier material when it suits.
- Interleave when practising a skill.
- Keep quiz options similar in length and shuffle their order, so an answer's shape never hints.

## Sources

- Cite every claim from `sources.md`.
- Point to related lessons and material.
- Name the single best source for going further.
- End by inviting questions.

## Build

- Write the shared stylesheet first, and put reusable components beside it.
- Anything a later lesson might reuse goes in the shared files, not inline.
- Keep working when opened from disk, offline if it can.

## Check before opening

- One idea only. If two fit, split them into two lessons.
- The win is something the user can do, not something they read.
- Each claim has its citation.
- A quiz's answer can't be guessed from its shape.
