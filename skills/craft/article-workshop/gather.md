# Gather

The aim is range: get everything that could be written onto the page before any structure narrows it. It all lands in one Markdown file that keeps growing, with its pieces in no order.

## Setup

Ask once for the file path. Start the file with a working title and nothing else.

## Method

- Interview hard and keep pressing, as the skill `question-tree` does. Use no outline and no phases.
- Start capturing with the very first thing said, from either side. The agent's good lines go in too.
- A piece needs to make sense only to its author. It can be a polished sentence or half a thought.
- Separate pieces simply, with no tags and no order.
- Push for one compact metaphor that names the central idea. It later shapes the structure and the title.
- Save without fuss, with a passing mention at most.
- Read the file again, then append. Never overwrite.
- When the user asks to cut, sharpen or merge pieces, do it.

## Judge pieces

Judge each piece as good writing. A piece doesn't need to be a self-contained argument.
